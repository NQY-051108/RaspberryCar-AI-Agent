# YOLOv8n 训练记录

此目录精选自本次 `traffic_sign_v8n` 训练输出，未重新执行训练或精度验证。

- 配置：YOLOv8n、640 输入、batch 8、最多 200 轮、patience 40，禁止水平与垂直翻转。
- `results.csv` 记录实际 96 轮，按 mAP50-95 最高值选出的最佳轮次为第 56 轮。
- 第 56 轮：Precision 0.63914，Recall 0.69042，mAP50 0.70013，mAP50-95 0.41719。
- 训练配置有 20 类，现有验证集只覆盖 13 类；缺失类别不能由这些整体指标证明性能。
- 本地标注核算：训练 505 张、1182 个框；验证 125 张、279 个框，其中 98 份非空标注、27 份空标注。旧人工验证报告中的 101/24 分组未采用。

`results.png` 是训练曲线，`confusion_matrix*.png` 和 `BoxPR_curve.png` 是保存的验证图。数据集与完整实验目录不随代码提交，部署模型与训练 `best.pt` 见 [模型说明](../../models/README.md)。
